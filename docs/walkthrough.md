# 现场复核

先在画外完成依赖或镜像准备。服务就绪检查为 `/health`，启动不下载资料。打开首页，选择材料轮次，查看分口径汇总约束与未披露单元；从任一明细点开原始记录核对。保存一次当前材料，然后改动选择并重新计算，再打开刚才的记录，确认原范围仍在，最后导出。

## 交叉人群问题

1. 在“交叉人群证据范围”中勾选分母人群与结果条件（例如分母 `income=low`、结果 `subsidy=yes`），点击“分析这个交叉问题”。
2. 先看结论标签：唯一可确定、仍有多种可能、材料互相冲突、未定义或材料不足以回答。
3. 核对“回答依赖的表”：确认答案只用了同单位、同户数计数、同总体、同期间的表；未并入的表会写明原因。
4. 若显示材料冲突，按“可核对的冲突组合”逐一核对两张表在共同维度上的分组合计，不要只挑一张表的结果。
5. 补入一张表后，在“补表后比较”中选择补表前的材料版本，比较同一问题的范围是否缩小；范围缩小不等于接近真实值。
6. 点击“保存证据记录”或“保存比较记录”留存当次结论。之后导入新表或切换版本，再从“分析记录”打开旧记录，仍应显示保存时的材料与区间。

上述浏览操作的设计时长为45至75秒，留出异常提示时间后不超过90秒；加入一次识别分析与一次补表比较后约需2至3分钟。部署故障不隐藏也不回放旧结果。新增分析的实际结果和可操作性须在功能完成后重新验证；这里不预报尚未开发能力的演示结果，不限定显著性或结论方向。
